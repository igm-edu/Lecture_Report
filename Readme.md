# 강의평가 확인서 생성기 (웹앱)

RAW 엑셀을 올리면 서식이 적용된 **강의평가결과 .xlsx** 를 바로 내려받습니다.
설치·로그인·인터넷 연결 모두 필요 없습니다.

## 실행

`index.html` 을 **더블클릭** (크롬 또는 엣지 권장)

> 즐겨찾기에 등록해 두면 다음부터 클릭 한 번으로 열립니다.
> 폴더째 옮겨도 되지만 `index.html` · `xlsx.full.min.js` · `exceljs.min.js` **세 파일은 항상 같은 폴더**에 있어야 합니다.

## 사용 순서

| 단계 | 할 일 |
|---|---|
| **1** | Forms에서 받은 응답 파일(.xlsx)을 드래그해서 올립니다 |
| **2** | 고객사·과정명·일시·장소·강사·참석 인원을 입력합니다 |
| **3** | 미리보기에서 정렬·중복 통합 결과를 확인하고 `XLSX 다운로드` |

**자동으로 처리되는 것**

- 파일명에서 고객사·과정명 추출 (`[시노펙스] 과정명(1-11).xlsx` → 고객사 `시노펙스`)
- 정량 문항(10점 척도)·정성 문항 자동 판별 → 체크박스로 수정 가능
- 교육시간 `[7H]` 계산 (종료−시작−점심 1시간, 직접 수정 가능)
- 참석 인원을 입력하면 응답률 즉시 표시

**미리보기 읽는 법**

각 답변 왼쪽의 글자수 중 **주황색**은 80자를 넘거나 줄바꿈이 있어
행 높이 30 + 자동 줄바꿈으로 처리되는 항목입니다.

## 적용된 작업 규칙

| # | 규칙 | 처리 |
|---|---|---|
| 1 | 원본 텍스트 그대로 | 앞뒤 공백만 제거 |
| 2 | 기존 수식 준용 | 평균·등급·NPS·평가인원·응답률·글자수 6종 수식 + 계산값 캐시 |
| 3 | 정성질문 볼드 + `#C5D9F1` | 2번 이후 전 문항 |
| 4 | 정성답변 나눔고딕 10pt | 전 답변 |
| 5 | 글자수 내림차순 | 최종 표기 문자열 기준 |
| 6 | B열 `>` 볼드·음영 없음 | 흰 배경 |
| 7 | 80자 초과 → 높이 30 + 줄바꿈 / 이하 → 19 | 줄바꿈 포함 답변도 30 처리 |
| 8 | 정성답변 뒤 공백 행 1개 | 블록 사이 |
| 9 | 인쇄 영역 `A1:U마지막행` | 보조열 V~X 제외 |
| 10 | 중복 답변 `x 00` 통합 | 완전 일치 기준 |
| 11 | 주제 D~I 병합 + 왼쪽 맞춤 | `D6:I6` |
| 12 | `00명 (응답률: 00.0%)` | `D8`·`E8` |

## 원본 양식과의 대조 결과

`_샘플출력_시노펙스.xlsx` 는 실제 로우데이터 11건으로 생성한 결과물입니다.
원본 양식과 대조해 아래 항목이 일치함을 확인했습니다.

- 제목 배경 `#03428E` / 정량 `#BFDBFD` / 정성 `#C5D9F1` / 표 머리글 `#D9D9D9`
- 폰트 — 나눔스퀘어 16pt(제목), 나눔고딕 11pt(머리글), 나눔고딕 10pt(답변), 9pt(보조열)
- 숫자 서식 — `0"명"`, `"(응답률: "0.0%")"`, `#,##0.0_`, `0.0%`, `0_);[Red]\(0\)`
- 행 높이 — 13.15 / 30 / 20.1 / 43.9 / 18.95
- 병합 — `B2:T2`, `B4:C4`, `D4:G4`, `D6:I6`, `B12:D12`, `E12:I12`, `E13:F13`, `G13:H13`, `C행:T행`
- 격자선 숨김, 인쇄 영역 `$A$1:$U$64`

## 서식을 바꾸고 싶으면

`index.html` 상단의 **`CFG`** 객체 한 곳만 수정하면 전체에 반영됩니다.

```js
const CFG = {
  FONT_TITLE:'나눔스퀘어', FONT_BODY:'나눔고딕',
  C_Q_QUAL:'FFC5D9F1',        // 정성 문항 음영
  H_SHORT:18.95, H_TALL:30,   // 행 높이
  WRAP_LEN:80,                // 줄바꿈 기준 글자수
  ...
};
```

## 문제가 생기면

| 증상 | 원인·해결 |
|---|---|
| 페이지가 비어 보임 | `xlsx.full.min.js`·`exceljs.min.js` 가 같은 폴더에 있는지 확인 |
| "읽기 실패" | 1행이 문항 머리글, 2행부터 응답인지 확인 |
| 정성 문항이 잘못 잡힘 | 2단계 체크박스에서 직접 선택/해제 |
| 다운로드가 안 됨 | 브라우저 다운로드 차단 해제. 크롬·엣지 권장 (인터넷 익스플로러 미지원) |
| 한글 폰트가 깨져 보임 | PC에 나눔고딕·나눔스퀘어 설치 필요 (없으면 기본 폰트로 표시) |
